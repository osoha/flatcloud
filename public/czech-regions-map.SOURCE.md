# Czech regions map asset

The map silhouette and regional divisions use the clean map object from the user-supplied WIP deck `FlatCloud_H1_2025_v3_slide8_table_restyled.pptx`. Its geometry was visually cross-checked against the authoritative `FlatCloud_H1_2025_v1 (1).pdf`; only the silhouette and regional divisions common to both sources were retained, and the colour follows the PDF. Property markers, callout lines, labels and photos are rendered dynamically and are not part of this asset.
